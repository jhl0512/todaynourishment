# 한 폭 — 명화 잠금화면 앱 (프로토타입)

화면을 켤 때마다 퍼블릭 도메인 명화와 짧은 문장을 보여 주는 안드로이드 잠금화면 앱 프로토타입이에요.

## 설치해 보기
- [`apk/hanpok-v0.1.apk`](apk/hanpok-v0.1.apk)를 열고 **Download raw file**(다운로드 버튼)으로 받아 안드로이드 폰에 설치해요. (출처를 알 수 없는 앱 설치 허용 필요)
- 처음 실행 후 설정에서 「잠금화면 켜기」, 실제 알림을 보려면 「잠금화면에 내 알림 보여 주기」를 허용해요.

## 폴더
- `src/` — 앱 화면(HTML·CSS·JS)과 작품·문장 데이터
- `build.py` — `src/`를 하나의 HTML로 묶는 빌드 스크립트
- `android/` — WebView로 감싼 안드로이드 프로젝트 (잠금화면 서비스, 알림 읽기, 카메라)
- `web/` — 바로 열어 볼 수 있는 웹 버전 (`web/index.html`: 여러 기기 크기 미리보기)

그림은 모두 퍼블릭 도메인 작품이에요.
